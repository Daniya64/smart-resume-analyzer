# Smart Resume Analyzer & Job Matcher

## About
A Python-based web application that analyzes resumes against job descriptions and identifies matching skills and skill gaps.

## Features
- PDF resume text extraction
- Resume and job description similarity score
- Skill matching and missing skill detection
- Personalized resume improvement suggestions
- Interactive score visualization
- Downloadable TXT and CSV reports

## Technologies
- Python
- Streamlit
- Pandas
- Scikit-learn
- PDFPlumber

## Run Locally
1. Install Python.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run `python -m streamlit run app.py`.

## Project Purpose
Built to practice Python programming, NLP-related text analysis, and interactive dashboard development.
